# RBG CAN Insight Privacy Policy

Last updated: 14 November 2026

RBG CAN Insight is designed for local, offline CAN trace analysis.

The application processes files selected by the user on the user's device. It
does not require an account and does not intentionally upload CAN traces,
databases, diagnostic descriptions, generated reports or user projects to a
remote service.

RBG CAN Insight may store local preferences, recent files, presets, layouts and
application logs on the user's device to support normal operation. Users can
delete those files from the application data folder or remove them by
uninstalling the application.

No vehicle data, personal data or application telemetry is intentionally
collected by RBG CAN Insight.

The application does not discover or connect to vehicle interfaces, acquire
live traffic, transmit CAN frames, send diagnostic requests, or perform remote
coding or flashing. Diagnostic operations shown in the interface are decoded
from files that the user already recorded and selected locally.

https://github.com/Ruba94-cyber/RBG-can-insight-privacy.
