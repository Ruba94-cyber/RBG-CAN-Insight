# RBG CAN Insight 5.2.0

Analyze recorded CAN and UDS traffic locally on Windows. Use the MSI installer or the portable ZIP below for Windows desktop x64.

## Highlights

- Import supported trace formats and inspect recorded frames, timing and statistics.
- Load DBC databases, decode signals, explore plots, Change Matrix and Byte Matrix views.
- Inspect reconstructed ISO-TP/UDS transactions and review recorded diagnostics.
- Explore DID–CAN correlation and Data Studio analysis workflows.
- Read the included application terms offline from **Session & tools → License and commercial use**.
